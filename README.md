# ماسال — Vue 3

مشروع Vue 3 وVite، مع الحفاظ على تصميم النظام وحقوله وعملياته. يدعم النشر على GitHub Pages ونسخة HTML مستقلة. ربط الخادم وقاعدة البيانات وواجهات API مرحلة لاحقة.

## التشغيل

- للتطوير، استخدم Node.js 24 ثم `npm ci` و`npm run dev`، وافتح الرابط الذي يظهر في الطرفية.
- `npm run build` ينشئ الموقع الجاهز للنشر في `dist/` ويحدّث `masal.html`.
- `npm run preview` يعرض نسخة النشر محليًا.
- افتح `masal.html` مباشرة لتشغيل النسخة المستقلة دون Node.js.
- `index.html` هو مدخل Vite؛ تشغيل مصدر المشروع يحتاج خادم التطوير أو البناء.
- إرجاع البطاقات للمزود ينزّل ملف Excel مباشر من إدارة بطاقات المخزون.
- لتحديث النسخة المستقلة فقط: `npm run build:standalone`.
- صور خريطة الشوارع تحتاج الإنترنت؛ بقية الموارد الأساسية مضمّنة في النسخة المحلية.

## أين أجد الملفات؟

| المكان | المحتوى |
|---|---|
| `src/App.vue` | قالب الواجهة الرئيسي، المصدر المشترك للموقع والنسخة المستقلة |
| `src/main.js` و`src/runtime/` | تهيئة Vue، ترتيب تحميل وحدات النظام والتصميم |
| `src/js/` | ملفات منطق النظام وواجهة المستخدم |
| `src/css/` | التصميم والتخطيط والهوية البصرية |
| `assets/` | المكتبات والخطوط وبيانات الخرائط وتراخيصها |
| `docs/` | أدلة المشروع، المتطلبات وتوثيق الترتيب |
| `tests/` | اختبارات النظام |
| `samples/` | عينات استيراد تجريبية |
| `tools/` | أداة البناء وأدوات فحص هيكل المشروع والتشغيل |
| `references/` | ملفات المصدر المرجعية الأصلية، محفوظة محليًا ولا تُرفع تلقائيًا |
| `tmp/` | نتائج اختبارات جديدة؛ لا تُرفع |

## GitHub Pages

يبقى عنوان الموقع الحالي نفسه عند النشر إلى المستودع نفسه. من إعدادات المستودع، اختر **Settings → Pages → Source → GitHub Actions**. الملف `.github/workflows/deploy-pages.yml` يبني المشروع وينشر محتويات `dist/` عند رفع تغييرات فرع `main`، ويمكن تشغيله يدويًا. تستخدم الموارد مسارات نسبية، وتبقى روابط التبويبات بصيغة `#exports` وغيرها وتعمل عند تحديث الصفحة.

إعداد النشر موجود محليًا؛ لم تُغيّر إعدادات GitHub عن بُعد ولم تُرفع التغييرات. ينشر workflow ناتج البناء فقط. `references/` و`tmp/` مستبعدان من Git.

## التحقق

```sh
npm run build
node tools/check-project.cjs
node tests/test-pages-config.cjs
node tests/test-local-and-pages.cjs
node tests/test-wallet-theme-parity.cjs
```

بعد تشغيل `npm run preview` في طرفية ثانية:

```sh
node tests/test-vue-parity.cjs
node tests/test-vue-transactions.cjs
```

اختبارات المتصفح الحالية تحتاج Playwright وEdge؛ بعضها يستخدم مسار بيئة التطوير الحالية. اختبارات الإرجاع ومعرف الفئة والاختيار اليدوي تقبل `MASAL_TEST_URL` لفحص نسخة النشر. اختبار التطابق يقارن 34 صفحة بالنسخة المستقلة، مع الحقول والأزرار والتصميم والترجمة والعمليات. النسخة المستقلة والموقع المنشور لا يحتاجان Node أو Playwright لدى المستخدم.

## البيانات وحدود النسخة

البيانات محفوظة في المتصفح، وليست داخل ملف HTML. النسخة الاحتياطية للمجلد لا تشمل بيانات المتصفح؛ نقلها يحتاج تصدير نسخة احتياطية من داخل النظام. تغيير مسار الملف أو المتصفح قد يؤدي إلى استخدام مساحة تخزين مختلفة.

هذه ليست خدمة خادم متعددة المستخدمين بعد. OTP ما زال تجريبيًا، والمصادقة والصلاحيات المحلية لا تغني عن التحقق على الخادم عند الربط. لا تستخدم بطاقات أو أرصدة حقيقية في النسخة التجريبية.
