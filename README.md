# ماسال — الواجهة المحلية

نسخة Frontend محلية للعرض والتجربة، مع إمكانية نشرها كما هي على GitHub Pages. ربط الخادم وقاعدة البيانات وواجهات API مرحلة لاحقة.

## التشغيل

- افتح `masal.html` مباشرة لتشغيل النسخة المجمعة محليًا.
- `index.html` هو مدخل الموقع على GitHub Pages، ويستخدم `src/js/` و`src/css/` ومجلد `assets/`.
- أبقِ `decrypt.html` بجانب صفحتي التشغيل، لأنه مستخدم لفك ملفات التصدير المشفرة.
- بعد تعديل المصدر: `node tools/build.cjs` لتحديث `masal.html`.
- صور خريطة الشوارع تحتاج الإنترنت؛ بقية الموارد الأساسية مضمّنة في النسخة المحلية.

## أين أجد الملفات؟

| المكان | المحتوى |
|---|---|
| `src/js/` | ملفات منطق النظام وواجهة المستخدم |
| `src/css/` | التصميم والتخطيط والهوية البصرية |
| `assets/` | المكتبات والخطوط وبيانات الخرائط وتراخيصها |
| `docs/` | أدلة المشروع، المتطلبات وتوثيق الترتيب |
| `tests/` | اختبارات النظام |
| `samples/` | عينات استيراد تجريبية |
| `tools/` | أداة البناء وأدوات فحص هيكل المشروع والتشغيل |
| `references/` | ملفات المصدر المرجعية الأصلية، محفوظة محليًا ولا تُرفع تلقائيًا |
| `tmp/` | نتائج اختبارات جديدة؛ لا تُرفع |

راجع [تفاصيل الترتيب](docs/PROJECT-STRUCTURE.md) و[محضر التحقق](docs/ORGANIZATION-2026-09-29.md).

## GitHub Pages

بقي `index.html` في الجذر وبقي ملف `.nojekyll`. نُقلت المصادر إلى `src/` وعدّلت الروابط ومسارات الخطوط والبناء. لا يلزم تغيير عنوان الصفحة. عند رفع التغييرات، يجب تضمين مجلد `src/` الجديد وجميع الإضافات والنقل والحذف من المسارات القديمة، وليس رفع ملف HTML وحده.

لم يغيّر هذا الترتيب إعدادات GitHub عن بُعد. أُخرج الأرشيف وصور التجارب وأدوات الفيديو من فولدر المشروع إلى النسخة الاحتياطية الخارجية. `references/` و`tmp/` مستبعدان من Git. لا تعتمد على `_config.yml` كحماية وصول: مع `.nojekyll` قد تُنشر الملفات المتتبعة في المستودع؛ لا تضف بيانات حقيقية أو أسرارًا إليه.

## التحقق

```sh
node tools/check-project.cjs
node tests/test-pages-config.cjs
node tests/test-local-and-pages.cjs
node tests/test-wallet-theme-parity.cjs
```

اختبارات المتصفح الحالية تحتاج Playwright وEdge؛ بعضها يستخدم مسار بيئة التطوير الحالية. التشغيل العادي لا يحتاج Node أو Playwright.

## البيانات وحدود النسخة

البيانات محفوظة في المتصفح، وليست داخل ملف HTML. النسخة الاحتياطية للمجلد لا تشمل بيانات المتصفح؛ نقلها يحتاج تصدير نسخة احتياطية من داخل النظام. تغيير مسار الملف أو المتصفح قد يؤدي إلى استخدام مساحة تخزين مختلفة.

هذه ليست خدمة خادم متعددة المستخدمين بعد. OTP ما زال تجريبيًا، والمصادقة والصلاحيات المحلية لا تغني عن التحقق على الخادم عند الربط. لا تستخدم بطاقات أو أرصدة حقيقية في النسخة التجريبية.
