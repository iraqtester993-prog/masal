# إرجاع البطاقات للمزود

من «إدارة بطاقات المخزون» افتح الدفعة، ثم حدد البطاقات المطلوبة أو اضغط «تحديد المتبقي». اختر «إرجاع للمزود»، وأدخل السبب، وراجع عدد البطاقات والرصيد التشغيلي الذي سيُعلّق.

مدير النظام يؤكد الإرجاع وينزل ملف Excel مباشرة. المستخدم الآخر يرسل طلبًا للاعتماد؛ يظهر في «طلبات الإرجاع» حتى يعتمد مستخدم مخول الإرجاع وينزل الملف أو يرفضه مع السبب.

أثناء انتظار الموافقة تتوقف البطاقات المحددة عن البيع ويُعلّق رصيدها فقط. رفض الطلب يعيد حالة البطاقات ورصيدها السابقين. عند إتمام الإرجاع تصبح البطاقات مصدّرة وغير قابلة للبيع؛ لا يحدث إرجاع نقدي تلقائي ولا تتغير البطاقات المباعة أو غير المحددة.

«سجل الإرجاع» يجمع العمليات المكتملة والمرفوضة. يمكن إعادة تنزيل ملف العملية المكتملة دون خصم إضافي. ملفات Excel تحتوي Serial وPIN والانتهاء، وCVC والمرجع عند وجودهما، وتحافظ على الأصفار في الرموز.

«إجراءات أخرى» تجمع تعديل البيانات والتالف والإلغاء والإيقاف والاسترجاع وتصدير كشف دون رموز. تصدير الكشف لا يسحب بطاقات من المخزون. حُذفت أداة فك التشفير؛ ملفات الإرجاع الجديدة تُفتح مباشرة.
