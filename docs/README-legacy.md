# ماسال كاردز — Vue 3

واجهة عربية تفاعلية بهوية الكود المرسل: كحلي `#0B1E36`، فيروزي `#00C7B1`، خلفيات فاتحة، بطاقات بيضاء وخط Cairo محلي.

## التشغيل المباشر

افتح **masal.html** بالنقر المزدوج في Edge أو Chrome. الملف مستقل: Vue والخطوط والتنسيق والمنطق مضمّنة داخله، ولا يحتاج إلى إنترنت أو npm أو تشغيل خادم.

للتطوير، افتح **index.html** مع الملفات المرافقة. بعد أي تعديل شغّل `node build.cjs` لتحديث النسخة المستقلة. الكود الأصلي `code.html` وملف `DESIGN.md` محفوظان دون تعديل.

## ما هذه النسخة؟

نظام محلي تفاعلي ببيانات تجريبية يتيح تجربة مسارات العمل الأساسية في المخطط. ليس نظام إنتاج ماليًا أو خادمًا متعدد المستخدمين. عمليات المحافظ والبيع والتدقيق والمراجعة تنفذ على بيانات المتصفح؛ لا تُرسل رسائل ولا تتصل بمزود أو جهاز خارجي. اختيار مستخدم من أعلى الصفحة هو **محاكاة للدور** وليس مصادقة.

تُحفظ البيانات في localStorage. لا تستخدم رموز PIN أو Tokens أو بيانات مالية حقيقية. إغلاق الصفحة وفتحها في المتصفح نفسه يحتفظ بالبيانات عادةً، لكن النقل إلى متصفح أو مسار آخر، ومسح بيانات المتصفح، قد يفصل أو يمسح مساحة العمل. استخدم النسخ الاحتياطي لنقل البيانات.

## مسار تجربة مقترح

1. افتح البيع والطباعة واختر مركز النور ثم فئة زين وكمية 1.
2. أصدر البطاقة: تُخصم قيمة البيع من محفظة النقطة ويُستخدم مخزون وكالة بغداد.
3. اضغط «فشلت الطباعة». افتح الاستثناءات، واطلب إعادة الطباعة مع سبب.
4. البطاقة والرمز نفسهما، ولا يتكرر الخصم. أكد نجاح الطباعة.
5. راجع المخزون، والمحافظ، والتقرير، وسجل التدقيق.
6. اقترح سعرًا جديدًا لوكالة بغداد من حساب المدير. بدّل إلى «مشرف بغداد» واعتمد الطلب. صاحب الطلب لا يستطيع اعتماده بنفسه.
7. جرّب تحميل CSV يحتوي PIN مكررًا: تظهر نتيجة كل سطر قبل التحميل.
8. جرّب التحويل من بغداد إلى الكرادة أو إحدى نقاط بغداد. التحويل إلى فرع البصرة مرفوض.

## الملفات

- `masal.html`: نسخة مستقلة للعمل مباشرة دون إنترنت.
- `index.html` و`styles.css` و`app.js`: واجهة Vue القابلة للتعديل.
- `engine.js`: منطق الحسابات والمخزون والتسعير والطباعة.
- `assets/`: Vue 3.5.13 وخطوط Cairo المحلية.
- `decrypt.html`: فك ملفات التصدير المشفرة محليًا وتنزيل CSV.
- `REQUIREMENTS.md`: مطابقة وحدات الملف وحالة التنفيذ والحدود.
- `ARCHITECTURE.md`: مسار تحويل النموذج إلى نظام إنتاج.
- `test-engine.cjs` و`test-ui.cjs`: اختبارات الأعمال والمتصفح.

## التصدير والنسخ الاحتياطي

تقارير CSV تُفتح في Excel. استيراد المخزون يدعم XLSX وCSV وTXT وTSV، واستيراد الأسعار يدعم XLSX وCSV. النسخة الاحتياطية JSON غير مشفرة وتخص بيانات التجربة فقط.

تصدير الدفعات يستخدم AES-256-GCM ومفتاحًا مشتقًا من كلمة المرور عبر PBKDF2-SHA256 (210,000 دورة). يتم منع البطاقات المصدرة من البيع. افتح `decrypt.html` واختر الملف وأدخل كلمة المرور لاسترجاع CSV. لا يوفر الملف المحلي تنزيلًا محدود الصلاحية أو إلغاء وصول بعد التنزيل؛ هذان يتطلبان خادمًا.

## التحقق

`node test-engine.cjs` — اختبارات قواعد الأعمال بدون متصفح.

`node test-ui.cjs` — اختبار Edge بدون إنترنت، جميع الصفحات، بيع وفشل طباعة وإعادة طباعة، حفظ وإعادة تحميل، وشاشات الهاتف. مسار Playwright في ملف الاختبار خاص ببيئة التطوير الحالية ويمكن استبداله بمسار تثبيت محلي.

الواجهة تدعم العربية والإنجليزية والكردية السورانية، مع اتجاه LTR للإنجليزية وRTL للعربية والكردية. تبقى أسماء الوكلاء والمنتجات وبيانات المستخدمين كما أُدخلت. المصادقة الفعلية وربط API وطابعات POS ليست منفذة في هذه النسخة. التفاصيل كاملة في جدول المتطلبات.

## الوضع النهاري والليلي
زر القمر/الشمس في الشريط العلوي يبدّل المظهر ويحفظ التفضيل في المتصفح. الهوية وتوزيع بطاقات لوحة التحكم مستمدان من المرجع المرسل، مع إبقاء السايدبار والوظائف. ملف theme.css يضبط الألوان والأسطح للوضعين، ويضمّن build.cjs الخطوط وملفات التنسيق في masal.html.

## تحسينات الواجهة واللغات

- مبدّل اللغة في الهيدر يحفظ اللغة المختارة محليًا. القوائم والنماذج والأزرار والحالات والتنبيهات مترجمة؛ البيانات المدخلة لا تتغير عند تبديل اللغة.
- الأرقام المعروضة موحّدة إلى `0–9`، بما فيها التواريخ وأيام الشهر في العربية والكردية.
- بطاقات بدرجات فيروزية وزرقاء وبنفسجية وذهبية، مع تكييف الألوان للوضع الليلي.
- قوائم جانبية مجمعة قابلة للطي، مع مؤشرات فتح وإغلاق ودعم لوحة المفاتيح.
- زر `+` يفتح نافذة الإجراءات السريعة: البيع والطلبية وإضافة وكيل أو نقطة وإيداع وتذكرة، حسب الصلاحية.
- التحويل يعرض نافذة مراجعة بالمبلغ والمرسل والمستلم قبل التنفيذ؛ الرجوع لا يخصم أي رصيد.
- أزرار ذات حالات مرور وضغط وتركيز وتعطيل واضحة، وخطوط أكبر، وحصر تركيز لوحة المفاتيح داخل النافذة المفتوحة.

ملفات التخصيص: `locales.js` لقواميس اللغات، و`polish.css` للألوان والأزرار والقوائم، و`layout.css` للتجاوب. `node test-locales.cjs` يتحقق من اللغات والاتجاه والأرقام ومسارات النوافذ.

## إضافة الموظفين وأنواع الصلاحيات
أنشئ نوعًا مسمى من شاشة أنواع الصلاحيات وحدد إجراءاته، ثم أضف الموظف باسمه وإيميله وكلمة مروره واختر النوع. النوع قابل للإسناد لعدة موظفين وتنتقل تعديلاته إليهم. كلمات المرور تحفظ كمشتقات دون نص أصلي، وتبقى هذه نسخة محلية لا توفر تسجيل دخول بخادم. التفاصيل في MANAGEMENT-GUIDE.md.
